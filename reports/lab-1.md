# Отчёт: лабораторная 1

- Траектория: Python Core.
- Уровень: основной; дополнительно реализован типизированный декоратор времени.
- Итоговый коммит: `lab-1`.

## Выполненные требования

- Приём и валидация сдач из этапа А.
- Контракт `Analyzer` и неизменяемый `AnalysisReport` с версиями анализаторов.
- `LengthAnalyzer` считает непустые строки и возвращает объяснение без оценки.
- `TemplateAnalyzer` ищет точные строки разрешённых шаблонов, возвращает
  `similarity`, объяснение разрешённого совпадения и диапазоны `evidence`.
- `JsonlSubmissionSource` и `InMemorySubmissionSource` реализуют общий контракт.
- Источники передаются в сервис через композицию и `Protocol`.
- `AnalyzerRegistry` выбирает анализатор по идентификатору без ветвления по классам.
- Контекстный менеджер JSONL-источника закрывает файл при ошибке и раннем выходе.
- `timed` сохраняет метаданные функции и измеряет длительность последнего вызова.

## Проверки

```powershell
.\.venv\Scripts\python -m pytest
.\.venv\Scripts\school-import examples\submissions.jsonl --assignments examples\assignments.json
.\.venv\Scripts\school-import examples\invalid_submissions.jsonl --assignments examples\assignments.json
```

Тесты проверяют успешный импорт, повреждённый JSON, неверные типы, дубликат,
конфликт, ошибку анализатора, диапазоны evidence, неизменность входных данных
и освобождение ресурса источника.

## Ограничения

- Хранилище остаётся in-memory и живёт только до конца процесса.
- Внешние анализаторы могут подключаться через entry points группы
  `online_school.analyzers`, но в проекте используются встроенные реализации.
- Код из сдачи не исполняется.
